# Sample data

Every file below is synthetic: invented forum-style and support-call-style texts about drugs and
side effects, and the rows extracted from them, generated by
[`generate_sample.py`](generate_sample.py) from sentence templates and two small vocabularies
(25 drug names and 30 side effects). No real patient, conversation or record is used. Licence:
CC0-1.0. The folder is about 70 KB, far under the 5 MB per file and 20 MB per folder limits.

| File | What it is | Where it came from | Licence | Synthetic |
| --- | --- | --- | --- | --- |
| `ade_events.parquet` | 300 invented texts with their ADE label: text_id, text, is_ade (150 true, 150 false) | Generated by `generate_sample.py` | CC0-1.0 | yes |
| `ade_classification.parquet` | The predicted ADE flag per text, as the `classify_ade` job produces it: text_id, predicted_ade | Written by the generator: the label, with 18 texts (6 percent) flipped | CC0-1.0 | yes |
| `entities.parquet` | 574 ADE and DRUG mentions: text_id, chunk, entity, confidence | Written by the generator from the same templates as the texts | CC0-1.0 | yes |
| `assertions.parquet` | 243 assertion statuses, one per ADE mention: Present (110), Absent (33), Someone_else (30), Hypothetical (30), Possible (25), Conditional (15) | Written by the generator from the same templates as the texts | CC0-1.0 | yes |
| `relations.parquet` | 262 ADE-DRUG pairs: relation ("1" for 219 pairs the text ties together, "0" for 43 it keeps apart), entity1, chunk1, entity2, chunk2, confidence | Written by the generator from the same templates as the texts | CC0-1.0 | yes |
| `graph_nodes.parquet` | 55 knowledge-graph nodes (25 Drug, 30 ADE), one row per node | Built from the tables above by the `build_knowledge_graph` job | CC0-1.0 | yes |
| `graph_edges.parquet` | 462 knowledge-graph edges, one fact per row, with text evidence and character span (219 `HAS_ADVERSE_EVENT`, 243 `ASSERTION`) | Built from the tables above by the `build_knowledge_graph` job | CC0-1.0 | yes |

Every row of the extracted tables carries the `text_id` of the text it came from, and the
graph's `evidence_document_id` holds the same value.

The texts mix an ADE the writer had (Present), one the writer denies (Absent: "no rash at all"),
one the writer is unsure about (Possible), one only feared or read about (Hypothetical), one that
depends on a condition (Conditional), one that happened to someone else ("my mum gets nausea
from metformin"), and texts with no ADE at all (questions, dosing, praise). Some texts have two
drugs or two ADEs. Some drug-ADE pairs are much more common than others, so the pair analyses
show a pattern.

`entities`, `assertions` and `relations` are what a text model would return for each text. Here
they are exact by construction, because they come from the same templates as the texts; they are
not the output of a model. `tests/recorded_answers.json` replays them, together with the
classification, so the four extraction jobs run without a model.

The predicted flags in `ade_classification` are invented to exercise the metrics: they equal the
label except for 18 texts chosen with a fixed seed, so accuracy and the confusion matrix have
something to show. They say nothing about any classifier.

To regenerate (the same seed always gives the same files):

```
uv run python data/generate_sample.py
```
